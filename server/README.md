# سامانه مدیریت و پایش شاخص‌های کلیدی عملکرد
## KPI Management & Monitoring System (KPI-MS)

سامانه‌ای تحت وب برای **جایگزینی فایل اکسل شاخص‌های سازمان**، طراحی‌شده بر اساس ساختار واقعی فایل ورودی (۱۶۴ شاخص در ۱۶ فرایند). این مخزن شامل **نمونه اولیهٔ کارآمد و قابل اجرا** به‌همراه **مستندات کامل طراحی مهندسی (PRD، معماری، مدل داده، UI/UX، گردش‌کار، API و پیشنهاد فناوری)** است.

> نسخهٔ نمونه با ۱۶۴ شاخص واقعیِ استخراج‌شده از فایل شما، داده‌های عملکردی سه سال شمسی (۱۴۰۳، ۱۴۰۴ و بخشی از ۱۴۰۵)، تقویم شمسی، RBAC چهار‌نقشه، داشبورد مدیریتی و خروجی Excel/PDF ارائه می‌شود.

---

## ⚡ اجرای سریع (نمونهٔ خودکفا با SQLite)

```bash
cd backend
pip install -r requirements.txt
python -c "from app.seed import run_seed; run_seed()"     # بارگذاری ۱۶۴ شاخص + داده نمونه
uvicorn app.main:app --host 0.0.0.0 --port 8000
# مرورگر: http://localhost:8000
```

## 🐳 اجرای Production (PostgreSQL + Docker)

```bash
cp backend/.env.example backend/.env      # تنظیم DATABASE_URL و KPI_SECRET_KEY
docker compose up -d --build              # api روی پورت 8000 + PostgreSQL
```

## 👤 حساب‌های نمونه (رمز همه: `Passw0rd!`)

| نام کاربری | نقش | دسترسی |
|-----------|-----|--------|
| `admin` | مدیر سیستم | کامل (شاخص‌ها، کاربران، ساختار، تنظیمات، لاگ) |
| `ceo` | مدیریت ارشد | داشبورد کلان، شاخص‌های استراتژیک (فقط مشاهده) |
| `quality` | مدیر کیفیت | پایش همه فرایندها، بررسی/تأیید، گزارش‌ها، ممیزی |
| `owner_pln` … `owner_hse` | مالک فرایند | ثبت داده و اقدام اصلاحی فرایند خودشان |

> 🔐 برابر با نسخه آفلاین، ورود با رمز پیش‌فرض `Passw0rd!` **تغییر اجباری رمز** را فعال می‌کند.
> اگر رمز مدیر فراموش شد، از لینک «رمز مدیر را فراموش کرده‌اید؟» در صفحه ورود و تایپ `RESET` استفاده کنید
> (بدون حذف داده‌ها). این امکان در «تنظیمات» قابل غیرفعال‌سازی است.

## 🧩 قابلیت‌های پیاده‌سازی‌شده در نمونه

- ✅ **موتور محاسبات KPI** — درصد تحقق (صعودی/نزولی، هدف صفر/منفی، سقف ۱۰۰٪) و تعیین وضعیت 🟢🟡🔴 با آستانه‌های قابل تنظیم
- ✅ **داشبورد مدیریتی** — کارت‌های کلان، توزیع وضعیت (Doughnut)، روند ۱۲ ماهه، وضعیت فرایندها (Stacked Bar)، **نمودار Pareto**، رتبه‌بندی فرایندها، شاخص‌های استراتژیک و بحرانی، **برترین/ضعیف‌ترین شاخص‌ها (تحقق بدون سقف)** و **نمودار راداری معاونت‌ها**
- ✅ **RBAC** چهار‌نقشه با کنترل دسترسی سطح داده (مالک فقط فرایند خود را می‌بیند) + **دسترسی صفحه‌به‌صفحه برای هر کاربر**
- ✅ **گردش‌کار ثبت→بررسی کیفیت→تأیید نهایی** با کارتابل و رد/اصلاح
- ✅ **مدیریت شاخص‌ها (KPI Master)** — CRUD کامل، تغییر فرمول/هدف، الزام «دلیل تغییر»
- ✅ **Audit-Log** — ثبت کاربر، تاریخ، مقدار قبل/بعد و دلیل هر تغییر
- ✅ **ساختار سازمانی درختی** — شرکت ← معاونت ← فرایند ← شاخص، با **CRUD شرکت‌های هلدینگ**
- ✅ **تقویم شمسی** در کل سامانه (ثبت، نمایش، فیلتر سال/ماه)
- ✅ **خروجی Excel و PDF** فارسی + **REST API** کامل با Swagger (`/docs`)

### 🔁 برابری کامل با نسخه آفلاین (KPI-SYSTEM-Strategy.html)

| قابلیت | وضعیت در نسخه سرور |
|--------|--------------------|
| داشبورد هلدینگ (مقایسه شرکت‌ها، میانگین وزنی، برترین شرکت) | `GET /api/holding/overview` · صفحه «داشبورد هلدینگ» |
| مدیریت شرکت‌های هلدینگ | `GET/POST/PUT/DELETE /api/companies` · صفحه «شرکت‌های هلدینگ» |
| اهداف استراتژیک + برنامه اقدام + شرط شروع + تاریخچه رویداد | `routers/strategy.py` · صفحه «اهداف و برنامه‌ها» |
| ارزیابی هدف بر پایه تازگی داده، پوشش و پیشرفت وزنی | `GET /api/strategy/goals` (asof) |
| تحلیل آماری چندساله (T زوجی/ولش، اصلاح هولم، بازنگری روند) | `GET /api/kpis/{id}/analysis` + پنل تحلیل در جزئیات شاخص |
| گزارش دوره‌ای با بازه تاریخ شمسی (میانگین/آخرین مقدار، فقط تأییدشده) | `GET /api/reports/range(.csv/.xlsx/.pdf)` |
| گزارش داده‌های ناقص/بدون داده (با مهلت دوره) | `GET /api/reports/no-data(.xlsx/.pdf)` |
| خروجی فهرست شاخص‌ها (همه/فعال/غیرفعال) | `GET /api/reports/list?scope=…&format=…` |
| پشتیبان‌گیری/بازیابی کامل (JSON) | `GET /api/reports/backup` · `POST /api/reports/restore` |
| بارگذاری داده نمونه و پاک کردن داده‌های عملکرد | `POST /api/settings/load-sample` · `POST /api/settings/clear-data` |
| قفل ورود پس از تلاش ناموفق، تغییر اجباری رمز پیش‌فرض، بازیابی مدیر با `RESET` | `routers/auth.py` + صفحه ورود |
| شاخص‌های تجمعی (MGT) — مقدار موثر مشتق‌شده و هشدار تحلیل | `effective.py` (در همه گزارش‌ها و تحلیل‌ها) |
| دسترسی صفحه‌به‌صفحه کاربر + مخفی‌شدن منو | `permissions.py` · `GET /api/users/views` |
| نصب به‌صورت اپلیکیشن (PWA) و باز شدن رابط پس از قطع شبکه | `manifest.webmanifest` · `sw.js` |

## 🗂️ ساختار پروژه

```
kpi-system/
├── backend/            # FastAPI + SQLAlchemy
│   ├── app/
│   │   ├── main.py           # اپ و سرو فرانت‌اند
│   │   ├── models.py         # مدل‌های ORM
│   │   ├── calc.py           # موتور محاسبات KPI
│   │   ├── jalali.py         # تقویم شمسی
│   │   ├── security.py       # JWT + RBAC
│   │   ├── seed.py           # بارگذاری ۱۶۴ شاخص
│   │   ├── stats.py          # آزمون‌های آماری (T، اصلاح هولم، روند)
│   │   ├── effective.py      # دوره سررسید، شاخص تجمعی MGT، نگاشت شرکت
│   │   ├── permissions.py    # دسترسی صفحه‌به‌صفحه کاربران
│   │   └── routers/          # auth, users, org, kpis, entries, dashboard,
│   │                         # reports, strategy, holding
│   ├── requirements.txt
│   └── Dockerfile
├── frontend/           # React (UMD) + htm — بدون مرحله build
│   ├── index.html
│   ├── manifest.webmanifest, sw.js   # PWA
│   └── static/app.js, styles.css, icons/
├── data/seed_kpis.json # ۱۶۴ شاخص پاک‌سازی‌شده
├── docs/               # مستندات مهندسی
└── docker-compose.yml
```

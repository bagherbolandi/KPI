# گزارش تکمیل نسخه سرور — برابری کامل با نسخه آفلاین

**تاریخ:** ۱۴۰۵/۰۸/۱۸ · **شاخه:** `arena/3bc1b0cf-kpi` · **نسخه سرور:** ۱.۱.۰

## ۱) خلاصه

نسخه سرور (FastAPI + SQLAlchemy + SPA بدون build) با نسخه آفلاین `KPI-SYSTEM-Strategy.html` هم‌تراز شد.
همه قواعد کسب‌وکار، متن‌های تصمیم آماری و رفتار صفحات از نسخه آفلاین گرفته شده‌اند؛ در عین حال
قابلیت‌های اختصاصی نسخه سرور (گردش‌کار تأیید، Audit-Log، JWT، PostgreSQL/Docker) حفظ شده است.

## ۲) آنچه اضافه شد

| حوزه | خروجی |
|------|--------|
| اهداف استراتژیک | `routers/strategy.py` — هدف، اتصال شاخص، برنامه اقدام، شرط شروع، گزارش اجرا، رویدادها، ۴ هدف نمونه |
| هلدینگ و شرکت‌ها | `routers/holding.py` — مقایسه شرکت‌ها، میانگین وزنی، CRUD شرکت |
| تحلیل آماری | `stats.py` + `GET /api/kpis/{id}/analysis` — T زوجی/ولش، اصلاح هولم، شیب روند، هشدار MGT |
| گزارش‌ها | `GET /api/reports/range(.csv/.xlsx/.pdf)`، `/reports/no-data`، `/reports/list`، `/export/csv` |
| پشتیبان/داده | `GET /api/reports/backup`، `POST /restore`، `POST /settings/load-sample`، `POST /settings/clear-data` |
| امنیت ورود | قفل حساب (۵ تلاش/۵ دقیقه)، تغییر اجباری رمز پیش‌فرض، بازیابی مدیر با `RESET` |
| دسترسی | `permissions.py` (۱۴ کلید)، `GET /api/users/views`، فیلتر منو و محافظ مسیر در SPA |
| داشبورد | برترین/ضعیف‌ترین شاخص‌ها، رادار معاونت‌ها، فیلتر شرکت |
| PWA | `manifest.webmanifest` + `sw.js` + آیکن‌ها (کش پوسته، API همیشه از شبکه) |

صفحه بازیابی مدیر و تغییر اجباری رمز.

## ۴) تصمیم‌های مهم

1. **MGT (شاخص تجمعی):** مقادیر به‌صورت «مقدار موثر» از شاخص‌های پایه محاسبه می‌شود؛ در تحلیل آماری
   آزمون معناداری انجام نمی‌شود و پیام «نیازمند بررسی مدیریتی» نمایش داده می‌شود (مطابق آفلاین).
2. **امنیت بازیابی مدیر:** `RESET` بدون احراز هویت است (هم‌ارز آفلاین) ولی با کلید
   `recovery_enabled` در تنظیمات می‌توان آن را غیرفعال کرد؛ همه عملیات در Audit-Log ثبت می‌شود.
3. **تغییر اجباری رمز:** ورود با رمز پیش‌فرض `Passw0rd!` کاربر را به صفحه تغییر رمز می‌برد (هم‌ارز آفلاین).
4. **داده نمونه:** `load-sample` هرگز دوره‌های آینده سال جاری را نمی‌سازد.
5. **PWA:** فقط پوسته رابط کش می‌شود؛ داده‌ها همیشه تازه‌اند (بدون کش API).

## ۵) اجرا

```bash
cd server/backend
pip install -r requirements.txt
python -c "from app.seed import run_seed; run_seed()"
uvicorn app.main:app --host 0.0.0.0 --port 8000
# http://localhost:8000  —  مستندات: /docs
```

حساب‌های نمونه: `admin` / `ceo` / `quality` / `owner_pln` … با رمز `Passw0rd!`
(در نخستین ورود، تغییر رمز اجباری است).

## ۶) محدودیت‌ها

- آزمون رابط کاربری با jsdom انجام شده (بدون مرورگر واقعی)؛ رندر نمودارها فقط از نظر خطای منطقی بررسی شده است.
- بازیابی پشتیبان کل داده‌های دامنه را جایگزین می‌کند؛ در محیط عملیاتی ابتدا از وضعیت فعلی پشتیبان بگیرید.

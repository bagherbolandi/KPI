# طراحی رابط و تجربه کاربری (UI/UX)

## ۱. اصول طراحی

- **RTL بومی و فارسی کامل** با فونت **Vazirmatn** و **اعداد فارسی** در تمام سامانه.
- **طراحی نقش‌محور**: منو و اقدامات هر کاربر بر اساس نقش او فیلتر می‌شود (کاهش بار شناختی).
- **رنگ‌بندی معنایی**: 🟢 سبز (مطلوب) / 🟡 زرد (نیازمند توجه) / 🔴 قرمز (بحرانی) به‌صورت یکسان در کارت‌ها، جدول‌ها و نمودارها.
- **سلسله‌مراتب بصری**: کارت‌های آماری کلان بالا، سپس نمودارها، سپس جدول‌های جزئی.
- **پیوستگی**: نوار کناری ثابت، نوار بالای چسبان با فیلتر «سال مالی» سراسری، و اعلان‌های Toast.

## ۳. نقشهٔ صفحات (Site Map)

```
ورود (Login)
└── پوستهٔ اصلی (Sidebar + Topbar + فیلتر سال)
    ├── پایش و تحلیل
    │   ├── داشبورد مدیریتی        (همه نقش‌ها)
    │   ├── فرایندها                (کارت هر فرایند + گیج)
    │   ├── شاخص‌ها و روندها         (جدول فیلترشونده + مودال جزئیات/روند)
    │   └── گزارش‌ها و خروجی         (Excel / PDF / API)
    ├── ثبت و گردش‌کار
    │   ├── ورود اطلاعات            (مالک فرایند / مدیر سیستم)
    │   └── کارتابل تأیید            (مدیر کیفیت / مدیر سیستم) — با شمارندهٔ نشان
    └── مدیریت سیستم
        ├── مدیریت شاخص‌ها (KPI Master)   (مدیر سیستم)
        ├── ساختار سازمانی               (درخت)
        ├── کاربران و نقش‌ها             (مدیر سیستم)
        ├── لاگ تغییرات                  (Audit)
        └── تنظیمات                      (آستانه‌ها، سال، نام سازمان)
```

## ۴. شرح صفحات کلیدی

### ۴.۱ داشبورد مدیریتی (Executive)
- **ردیف کارت‌های کلان:** کل شاخص‌ها · میانگین تحقق (ساده و وزنی) · شاخص‌های مطلوب · شاخص‌های بحرانی.
- **نمودار Doughnut:** توزیع وضعیت سبز/زرد/قرمز/بدون‌داده.
- **نمودار خطی:** روند ۱۲ ماههٔ تحقق سازمان.
- **کارت شاخص‌های استراتژیک:** OEE، CSAT، ضایعات، تحقق برنامه تولید و … با وضعیت.
- **نمودار میله‌ای انباشته (افقی):** وضعیت شاخص‌ها به تفکیک فرایند.
- **نمودار Pareto:** تمرکز شاخص‌های بحرانی و منحنی تجمعی (قانون ۸۰/۲۰).
- **جدول رتبه‌بندی فرایندها** + **جدول شاخص‌های بحرانی**.

### ۴.۲ شاخص‌ها و روندها
جدول فیلترشونده (جستجو، فرایند، سطح اهمیت) با کد، نام، جهت (🔺/🔻)، هدف، حد هشدار، تناوب. کلیک → **مودال جزئیات**: مشخصات کامل، تعریف/فرمول، و **نمودار روند عملکرد در برابر هدف** (خط واقعی + خط‌چین هدف).

### ۴.۳ ورود اطلاعات (مالک فرایند)
انتخاب ماه شمسی؛ جدول شاخص‌های فرایند با ستون «عملکرد ماه»، درصد تحقق و وضعیت لحظه‌ای. فرم ثبت شامل مقدار واقعی، توضیحات، علت انحراف و اقدام اصلاحی؛ دکمه‌های «ذخیره پیش‌نویس» و «ذخیره و ارسال برای تأیید».

### ۴.۴ کارتابل تأیید (کیفیت)
فهرست موارد در انتظار با اقدامات «تأیید / رد (با دلیل)»؛ نمایش وضعیت گردش‌کار و شمارندهٔ نشان روی منو.

### ۴.۵ مدیریت شاخص‌ها (KPI Master)
جدول کامل + فرم ایجاد/ویرایش با تمام فیلدهای Master. **در ویرایش، فیلد «دلیل تغییر» اجباری** است و در Audit ثبت می‌شود.

### ۴.۶ لاگ تغییرات (Audit)
فیلتر بر اساس نوع موجودیت؛ نمایش زمان، کاربر، عملیات، فیلد، **مقدار قبل/بعد** و دلیل.

## ۵. جریان‌های تعاملی کلیدی (User Flows)

1. **مالک فرایند** → ورود اطلاعات → انتخاب ماه → ثبت مقدار → «ارسال برای تأیید» → مشاهده وضعیت در کارتابل.
2. **مدیر کیفیت** → کارتابل → بررسی → تأیید/رد → داشبورد به‌روزرسانی می‌شود.
3. **مدیریت ارشد** → داشبورد → مشاهده Pareto و شاخص‌های بحرانی → گزارش PDF.
4. **مدیر سیستم** → KPI Master → ویرایش هدف با ثبت دلیل → بررسی رد‌پا در Audit.

## ۶. دسترس‌پذیری و واکنش‌گرایی
- چیدمان Grid واکنش‌گرا (۴/۲/۱ ستونه بر اساس عرض صفحه).
- کنتراست رنگی مناسب برای وضعیت‌ها؛ نشانه‌های متنی علاوه بر رنگ (Badge با متن).
- سازگاری با شبکهٔ داخلی و مرورگرهای سازمانی (بدون وابستگی CDN در استقرار — دارایی‌ها محلی).

## ۷. یادداشت پیاده‌سازی نمونه
همهٔ صفحات بالا در نمونهٔ اجرایی پیاده‌سازی و با تست خودکار مرورگری (Playwright) تأیید شده‌اند: رندر بدون خطا، ۴ نمودار داشبورد، ۱۶۴ ردیف شاخص، مودال روند، و صحت دسترسی هر ۴ نقش.
